# Smart Traffic System

**Smart Traffic System** — это интегрированное решение для моделирования и управления умными светофорами. Проект объединяет следующие подсистемы:

- **Контроллеры светофоров**
  - Традиционные (фиксированные циклы)
  - Адаптивные (с учетом плотности трафика и прогнозированием изменений)
- **Детекция транспортных средств**
  - Обработка видеопотока с использованием модели YOLOv8 (через пакет ultralytics)
  - Трекинг объектов для отслеживания перемещения ТС
- **Симуляция транспортного потока**
  - Моделирование движения транспортных средств по дорогам и перекресткам
  - Генерация транспортного потока с планированием событий и сбором метрик
- **Визуализация и анализ результатов**
  - Интерактивная визуализация симуляции с использованием Pygame
  - Построение графиков и диаграмм (Matplotlib, Seaborn)
  - Обработка и анализ данных симуляции через Pandas
