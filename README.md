# Smart Traffic System

**Smart Traffic System** — это интегрированное решение для моделирования и управления умными светофорами. Проект объединяет следующие подсистемы:

- **Контроллеры светофоров**
  - Традиционные (фиксированные циклы)
  - Адаптивные (с учетом плотности трафика и прогнозированием изменений)
- **Детекция транспортных средств**
  - Обработка видеопотока с использованием модели YOLOv8 (через пакет ultralytics)
  - Трекинг объектов для отслеживания перемещения ТС
- **Симуляция транспортного потока**
  - Моделирование движения транспортных средств по дорогам и перекресткам
  - Генерация транспортного потока с планированием событий и сбором метрик
- **Визуализация и анализ результатов**
  - Интерактивная визуализация симуляции с использованием Pygame
  - Построение графиков и диаграмм (Matplotlib, Seaborn)
  - Обработка и анализ данных симуляции через Pandas

## Подготовка и запуск

1. **Установка зависимостей**

   Для установки всех необходимых зависимостей выполните команду:

   ```bash
   pip install -r requirements.txt
   Конфигурация
   ```

Все конфигурации находятся в каталоге config/. Пример конфигурационных файлов:

simulation.yaml – настройки симулятора (дороги, перекрёстки, генераторы трафика, запланированные события).

visualization.yaml – настройки визуализации (размер окна, цвета, параметры камеры, интерфейс).

Запуск

Для системного запуска (с выбором режима) используйте:

python main.py --config config/simulation.yaml --mode simulation --controller smart --duration 3600

Дополнительные аргументы:

--video <path> – путь к видеофайлу для режима детекции.

--output <path> – путь для сохранения результатов.

--debug – включение режима отладки.

--no-gui – запуск без графического интерфейса (режим для сервера).

Для запуска отдельной симуляции:

python run_simulation.py

Для сравнения контроллеров:

python run_comparison.py

Для обработки видео:

python run_detection.py --video your_video.mp4

Логирование и отчёты
Логирование настраивается через utils/logger.py и сохраняется в файл system.log. После завершения работы система генерирует итоговый отчёт, который можно просмотреть в консоли или сохранить в указанный файл (например, CSV для метрик сравнения).

Требования к системе
Проект написан для Python 3.7+.

Автор и лицензия
Этот проект является примером интеграции интеллектуальных систем управления дорожным движением. Распространяется по лицензии MIT.

Дополнительные замечания по доработке проекта
Интеграция компонентов.

Все модули объединены в класс SmartTrafficSystem в файле smart_traffic_system.py, который обеспечивает взаимодействие между симулятором, детектором, визуализатором, контроллерами, коллекторами метрик и логированием.

Для каждого режима работает соответствующий скрипт: run_simulation.py, run_comparison.py, run_detection.py.

Валидация конфигураций.

В файле utils/config_loader.py реализованы базовые функции загрузки и сохранения конфигурации. При необходимости можно расширить метод validate_config с использованием библиотеки jsonschema.

Логирование.

Класс Logger в utils/logger.py настраивает логирование как в консоль, так и в файл.

Модуль визуализации.

visualization/traffic_visualizer.py использует Pygame для реального отображения симуляции.

visualization/performance_plotter.py и visualization/comparison_analyzer.py используют Matplotlib и Seaborn для построения графиков и анализа результатов.

visualization/data_processor.py обеспечивает обработку и агрегацию данных симуляции.

Детекция транспорта.

Модуль detection/ содержит компоненты для обработки видеопотока, обнаружения транспортных средств и управления детекцией.

Совместимость.

Все импорты и вызовы методов сверены и отлажены в соответствии с логикой системы. Stub-реализации (например, алгоритмы принятия решений, прогнозирование) можно заменить на полноценные реализации по мере необходимости.
